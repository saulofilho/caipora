Caipora

clique numa casa

A1

Do tupi ka'a pora, “habitante do mato”. A Caipora conhece cada trilha da floresta e espalha pistas falsas para quem caça além da conta. Esta ferramenta faz o mesmo com a sua IA: anda por cada casa do mapa, com ataques em português, antes que outra pessoa ande.

B1

O que ela faz

Losango · chatbots

42 ataques em português, de vazamento de CPF a golpe do Pix e falsa autoridade da ANPD. Oito detectores de dados brasileiros com dígito verificador acusam o que escapou na resposta.

Trama · agentes

Um honeypot com ferramentas falsas, documentos envenenados e valores-canário. Você vê o que o agente faz, não só o que ele diz.

Zigue-zague · MCP

Auditoria de servidores MCP sem executar nada: instruções escondidas, caracteres invisíveis, ferramentas que se fazem passar por outras.

Greca · CI

Roda a cada PR, compara com a branch principal e quebra o build quando algo que era seguro passa a vazar.

Bestiário

Cada família de ataque tem o seu bicho.

Saci
jailbreakPersonas sem regras, o golpe da vovó, “ignore as instruções anteriores”.
Curupira
injection indiretaPés virados para trás: instruções escondidas em documentos, arquivos e cadastros.
Iara
golpeO canto que puxa para o fundo: phishing, falso parente, central falsa do banco.
Boto
autoridade falsaDe chapéu, ninguém percebe: “sou da ANPD”, “sou delegado”, “sou do TI”.
Boitatá
vazamentoCPF, Pix, cartão e prompt de sistema escapando na resposta.
Mula sem cabeça
agência excessivaO agente que apaga, transfere e envia sem pensar.

D1

Como usar

  1. Instalar

    uv tool install git+https://github.com/saulofilho/caipora

  2. Atacar um chatbot

    caipora run http://localhost:8000/chat --llm ollama/qwen2.5:7b

    Também aceita uma função Python (app.py:responder) e qualquer API compatível com OpenAI como juiz.

  3. Soltar um agente no honeypot

    caipora run agente.py:agente -p agente

  4. Auditar um servidor MCP

    caipora mcp-auditar "python servidor.py" --falhar-em alta

  5. Guardar no CI

    caipora run ALVO --base base.json --falhar-se-regressao

    Há uma GitHub Action pronta no repositório.
